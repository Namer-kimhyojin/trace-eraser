Privacy Policy

Effective: November 6, 2026

Trace Eraser ("the app") helps you find and remove sign-in and personal traces left on a Windows PC. The app works entirely on your PC. It has no server, no account, and it does not collect, send or sell any information.

1. Information the app accesses on your PC

Only when you press Start scan, the app reads the following on this PC so it can show them to you:

  • Browser data: site addresses and usernames of saved logins (never the passwords), autofill entries, cookie counts per site, browsing history (addresses and titles), and addresses in tabs that would reopen.
  • App sign-ins: the location and size of sign-in files of AI apps, messengers and Office, and the names of sign-in keys in their settings files (not the token values).
  • Files & records: names of downloaded files and recently used files, Run / search / address bar history, whether the clipboard has content (not the content itself), Remote Desktop server names and username hints.
  • Korean digital certificates (NPKI): public certificate details (name, issuer, expiry). Private keys are never read.
  • Windows credentials: the name, user name, type and modified date of each entry. Secret values are never read.

The app never decrypts or displays saved passwords.

2. How the information is used

Only to show you what is on this PC and to delete the items you select. Nothing is used for any other purpose.

3. Storage

  • Scan results are kept only in memory and disappear when you close the app.
  • Deleted items go to the app's Trash so you can undo: they are encrypted with AES-256 and stored temporarily in %LOCALAPPDATA%\PrivacyCleaner\trash. The key exists only in the app's memory. When you close the app, the Trash is permanently erased. If the app ends abnormally, the remaining files cannot be decrypted by anyone and are erased the next time the app starts. You can also choose to delete permanently without using the Trash.
  • Your language and light/dark choice are saved in %LOCALAPPDATA%\PrivacyCleaner\prefs.json. Nothing else is saved.

4. Sharing and transmission

The app does not send any information to the developer or to third parties, and it contains no analytics, tracking or advertising SDK. Its window is displayed with Microsoft Edge using a temporary profile that is deleted when the app closes; Edge itself may contact Microsoft (for example, for updates and security checks) under Microsoft's privacy statement.

The app shows a small banner for the developer's other app (Air Calendar). Only if you click it, the Microsoft Store page opens; the link contains only a campaign label and no personal information. Microsoft's privacy statement applies to the Store.

5. Your choices

  • Nothing is scanned or deleted until you start it, and every deletion asks for confirmation.
  • The Trash is erased every time the app closes, so the only file left in %LOCALAPPDATA%\PrivacyCleaner is the small settings file. You can delete that folder at any time.

6. Children

The app does not collect information from anyone, including children.

7. Changes

If this policy changes, the new version will be posted on this page with a new effective date.

개인정보 처리방침

시행일: 2026년 11월 6일

개인정보 삭제 도구(Trace Eraser, 이하 "앱")는 Windows PC에 남은 로그인·개인정보 흔적을 찾아 지우도록 돕는 프로그램입니다. 앱은 사용자의 PC 안에서만 동작하며, 서버·계정이 없고 어떤 정보도 수집·전송·판매하지 않습니다.

1. 앱이 PC에서 확인하는 정보

사용자가 검사 시작을 누를 때에만, 화면에 보여 주기 위해 이 PC에서 다음을 읽습니다.

  • 브라우저 데이터: 저장된 로그인의 사이트 주소·아이디(비밀번호는 읽지 않음), 자동완성 입력값, 사이트별 쿠키 개수, 방문 기록(주소·제목), 다시 열릴 탭의 주소
  • 앱 로그인: AI 앱·메신저·Office 로그인 파일의 위치·크기, 설정 파일 속 로그인 항목의 이름(토큰 값은 읽지 않음)
  • 파일·기록: 다운로드·최근 사용 파일의 이름, 실행·검색·주소창 입력 기록, 클립보드에 내용이 있는지 여부(내용은 읽지 않음), 원격 데스크톱 서버 이름·아이디 힌트
  • 공동인증서(NPKI): 인증서 공개 정보(이름·발급기관·만료일). 개인키는 읽지 않습니다.
  • Windows 자격 증명: 항목의 이름·사용자·종류·수정일. 비밀 값은 읽지 않습니다.

앱은 저장된 비밀번호를 복호화하거나 보여 주지 않습니다.

2. 이용 목적

이 PC에 무엇이 남아 있는지 보여 주고, 사용자가 고른 항목을 지우는 데에만 씁니다. 다른 목적으로 쓰지 않습니다.

3. 보관

  • 검사 결과는 메모리에만 있고 앱을 닫으면 사라집니다.
  • 지운 항목은 되돌릴 수 있도록 앱 휴지통에 담깁니다. AES-256 으로 암호화되어 %LOCALAPPDATA%\PrivacyCleaner\trash 에 임시로 보관되며, 암호 키는 앱 메모리에만 있습니다. 앱을 닫으면 휴지통은 영구 삭제됩니다. 앱이 비정상 종료되면 남은 파일은 누구도 풀 수 없고, 다음 실행 때 삭제됩니다. 휴지통을 거치지 않고 바로 영구 삭제하도록 고를 수도 있습니다.
  • 언어와 밝은/어두운 화면 선택만 %LOCALAPPDATA%\PrivacyCleaner\prefs.json 에 저장합니다. 그 밖의 정보는 저장하지 않습니다.

4. 제공·전송

앱은 개발자나 제3자에게 어떤 정보도 보내지 않으며, 분석·추적·광고 SDK가 없습니다. 앱 화면은 Microsoft Edge 의 임시 프로필(앱을 닫으면 삭제)로 표시되며, Edge 자체는 업데이트·보안 확인 등을 위해 Microsoft 개인정보처리방침에 따라 Microsoft 와 통신할 수 있습니다.

앱에는 같은 개발자의 다른 앱(Air Calendar)을 소개하는 작은 배너가 있습니다. 사용자가 누를 때에만 Microsoft Store 페이지가 열리며, 링크에는 캠페인 표시만 있고 개인정보는 들어 있지 않습니다. 스토어에는 Microsoft 의 개인정보처리방침이 적용됩니다.

5. 사용자의 선택

  • 사용자가 시작하기 전에는 아무것도 검사하거나 지우지 않으며, 지울 때마다 확인을 받습니다.
  • 휴지통은 앱을 닫을 때마다 지워지므로 %LOCALAPPDATA%\PrivacyCleaner 에 남는 것은 작은 설정 파일 하나뿐이며, 이 폴더는 언제든 직접 지울 수 있습니다.

6. 아동

앱은 아동을 포함한 누구의 정보도 수집하지 않습니다.

7. 변경

이 방침이 바뀌면 새 시행일과 함께 이 페이지에 게시합니다.

プライバシー ポリシー

施行日: 2026 年 11 月 6 日

個人情報クリーナー（Trace Eraser、以下「本アプリ」）は、Windows PC に残ったログイン情報や個人情報の痕跡を見つけて削除するためのアプリです。本アプリはお使いの PC の中だけで動作し、サーバーやアカウントはなく、情報の収集・送信・販売は一切行いません。

1. 本アプリが PC 上で確認する情報

スキャン開始 を押したときにのみ、画面に表示するためにこの PC 上の次の情報を読み取ります。

  • ブラウザーのデータ: 保存されたログインのサイト アドレスとユーザー名（パスワードは読み取りません）、自動入力の値、サイトごとの Cookie の数、閲覧履歴（アドレスとタイトル）、次回また開くタブのアドレス
  • アプリのログイン: AI アプリ・メッセンジャー・Office のログイン ファイルの場所とサイズ、設定ファイル内のログイン項目の名前（トークンの値は読み取りません）
  • ファイル・履歴: ダウンロードしたファイルや最近使ったファイルの名前、実行・検索・アドレス バーの入力履歴、クリップボードに内容があるかどうか（内容は読み取りません）、リモート デスクトップのサーバー名とユーザー名のヒント
  • 韓国の電子証明書（NPKI）: 証明書の公開情報（名前・発行者・有効期限）。秘密鍵は読み取りません。
  • Windows 資格情報: 各項目の名前・ユーザー・種類・更新日。秘密の値は読み取りません。

本アプリは保存されたパスワードを復号したり表示したりしません。

2. 利用目的

この PC に何が残っているかを表示し、ユーザーが選んだ項目を削除するためだけに使います。それ以外の目的には使いません。

3. 保存

  • スキャン結果はメモリ上にだけあり、アプリを閉じると消えます。
  • 削除した項目は元に戻せるようにアプリのごみ箱に入ります。AES-256 で暗号化して %LOCALAPPDATA%\PrivacyCleaner\trash に一時的に保存し、暗号キーはアプリのメモリ上にだけあります。アプリを閉じるとごみ箱は完全に削除されます。アプリが異常終了した場合、残ったファイルは誰にも復号できず、次回の起動時に削除されます。ごみ箱を使わずにすぐ完全に削除することもできます。
  • 言語とライト / ダーク モードの選択だけを %LOCALAPPDATA%\PrivacyCleaner\prefs.json に保存します。それ以外の情報は保存しません。

4. 提供・送信

本アプリは開発者や第三者に情報を送信せず、分析・追跡・広告の SDK は含まれていません。アプリの画面は Microsoft Edge の一時プロファイル（アプリを閉じると削除）で表示されます。Edge 自体は、更新やセキュリティ確認などのために Microsoft のプライバシーに関する声明に従って Microsoft と通信する場合があります。

本アプリには、同じ開発者の別アプリ（Air Calendar）を紹介する小さなバナーがあります。ユーザーがクリックしたときにだけ Microsoft Store のページが開きます。リンクにはキャンペーンの識別子だけが含まれ、個人情報は含まれません。ストアには Microsoft のプライバシーに関する声明が適用されます。

5. ユーザーの選択

  • ユーザーが開始するまでは何もスキャン・削除せず、削除のたびに確認を求めます。
  • ごみ箱はアプリを閉じるたびに削除されるため、%LOCALAPPDATA%\PrivacyCleaner に残るのは小さな設定ファイルだけです。このフォルダーはいつでも削除できます。

6. 子ども

本アプリは子どもを含め、誰の情報も収集しません。

7. 変更

本ポリシーを変更した場合は、新しい施行日とともにこのページに掲載します。

隐私政策

生效日期：2026 年 11 月 6 日

隐私清理工具（Trace Eraser，以下简称“本应用”）帮助你找出并删除 Windows 电脑上残留的登录信息和个人信息痕迹。本应用完全在你的电脑上运行，没有服务器和账户，不会收集、发送或出售任何信息。

1. 本应用在电脑上查看的信息

只有在你点击开始扫描时，本应用才会读取这台电脑上的以下信息，以便显示给你：

  • 浏览器数据：已保存登录信息的网站地址和用户名（不读取密码）、自动填充内容、各网站的 Cookie 数量、浏览记录（地址和标题）、下次会重新打开的标签页地址
  • 应用登录：AI 应用、即时通讯软件和 Office 登录文件的位置和大小，以及设置文件中登录项的名称（不读取令牌的值）
  • 文件与记录：下载文件和最近使用文件的名称、运行 / 搜索 / 地址栏输入记录、剪贴板中是否有内容（不读取内容本身）、远程桌面服务器名称和用户名提示
  • 韩国数字证书（NPKI）：证书的公开信息（名称、颁发机构、到期日）。不读取私钥。
  • Windows 凭据：各项的名称、用户、类型和修改日期。不读取机密值。

本应用不会解密或显示已保存的密码。

2. 使用目的

仅用于显示这台电脑上残留的内容，并删除你选择的项目，不用于任何其他目的。

3. 存储

  • 扫描结果只保存在内存中，关闭应用后即消失。
  • 为了可以撤销，删除的项目会放入应用的回收站：使用 AES-256 加密后临时保存在 %LOCALAPPDATA%\PrivacyCleaner\trash，密钥只存在于应用的内存中。关闭应用时回收站会被永久清空。如果应用异常退出，剩余文件任何人都无法解密，并会在下次启动时被删除。你也可以选择不经过回收站直接永久删除。
  • 只有语言和浅色 / 深色模式的选择保存在 %LOCALAPPDATA%\PrivacyCleaner\prefs.json 中，不保存其他信息。

4. 共享与传输

本应用不会向开发者或任何第三方发送信息，也不包含分析、跟踪或广告 SDK。应用界面通过 Microsoft Edge 的临时配置文件（关闭应用时删除）显示；Edge 本身可能会根据 Microsoft 隐私声明与 Microsoft 通信（例如更新和安全检查）。

本应用中有一个介绍同一开发者另一款应用（Air Calendar）的小横幅。只有在你点击时才会打开 Microsoft Store 页面，链接中只包含活动标识，不包含个人信息。应用商店适用 Microsoft 的隐私声明。

5. 你的选择

  • 在你开始操作之前，本应用不会扫描或删除任何内容，每次删除都会请求确认。
  • 每次关闭应用时回收站都会被清空，因此 %LOCALAPPDATA%\PrivacyCleaner 中只会留下一个很小的设置文件。你可以随时删除该文件夹。

6. 儿童

本应用不收集任何人（包括儿童）的信息。

如果本政策有变更，将在此页面发布新版本并注明新的生效日期。
